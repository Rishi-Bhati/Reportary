{% trans "API Documentation & Integration Guide" %}

Reportary provides a secure developer API to submit issues, pull logs, and interface with project components programmatically.

Authentication

All requests must authenticate using a HTTP standard Authorization header containing your public key and plaintext secret key separated by a colon: 

Authorization: Bearer <public_key>:<secret_key>
POST /api/v1/reports/

Create a new issue inside the project scoped to the API key.

Request Body (JSON) 
{
  "title": "Bug Report via API",
  "description": "Steps to reproduce this bug...",
  "impact": "high",
  "frequency": "daily",
  "report_type": "bug",
  "custom_fields": {
    "os_version": "Ubuntu 22.04",
    "is_reproducible": true
  }
}
Fields Reference
Field Type Required Description
titlestringyesBrief summary of the issue
descriptionstringyesDetailed description
report_typestringnoCategory slug: bug, feature, vulnerability
impactstringnolow, medium, high, critical
frequencystringnoonce, daily, weekly, monthly
stepsstringnoSteps to reproduce
componentstringnoComponent UUID string
custom_fieldsobjectnoKey/value pairs for custom form fields
cURL Example 
curl -X POST \
  -H "Authorization: Bearer rpk_xxx:rsk_yyy" \
  -H "Content-Type: application/json" \
  -d '{"title": "Bug Title", "description": "Desc", "report_type": "bug", "impact": "high"}' \
  {{ request.scheme }}://{{ request.get_host }}/api/v1/reports/
