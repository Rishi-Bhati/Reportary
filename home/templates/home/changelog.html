What's New in Reportary

A running log of every improvement, security fix, and new feature shipped. Most recent first.

v1.0.0-beta.2 July 2026 · Security Hardening, Public Portals, & Organisation Upgrades Latest
New Feature

Public Portals & Anonymous Reporting

External users can now submit feedback anonymously through standalone project links at /p/<token>/. Includes drag-and-drop attachment dropzones, math CAPTCHAs and honeypots to block spam, secure rate limits, and GDPR-safe salted IP hashing. Project owners can fully customize link states, attachments, and regeneration.

Security Fix

Production Readiness Security Hardening

Remediated multiple vulnerabilities identified in the production readiness audit. Enforced strict UUID access checks, decoupled project managers from direct ownership, secured user search endpoints against database email scraping, and hardened cookie attributes (Samesite, HttpOnly) and HTTP headers. Added Cache-based rate limits to contact form submissions and fixed IP spoofing vulnerabilities.

New UX

Organisation Management Polish & Creation Flow

Introduced a dedicated Organisations button in both the sidebar and topbar profile navigation. Added profile details validation (Full Name, Business Email, Corporate Role) during organisation creation for users who did not sign up as organisation contact persons during onboarding.

UX New

Complete Worldwide Country Onboarding

Expanded the onboarding country dropdown menu from 3 placeholder options to a comprehensive list of all 195 countries globally via a unified, modular template include.

v1.0.0-beta.1 July 2026 · Major public beta release
Security Fix

Endpoint Security Hardening

Fixed multiple open endpoints accessible without authentication: /reports/get_components/, /reports/get_project_config/, /search/, and the profile page. All now enforce @login_required with project-level access scoping.

Security Fix

Global HTMX CSRF Token Fix

Fixed a critical issue where HTMX POST requests (task toggles, bookmarks, comment actions) were silently failing due to missing CSRF headers. All HTMX mutations now automatically include the CSRF token via a centralised htmx:configRequest handler in the base template.

New

Project Dashboard

Every project now has a dedicated dashboard — real-time statistics, a dynamic health score, recent reports, active collaborators, and a fully interactive task checklist. Tasks persist, can be toggled, added, and deleted without page reloads.

New

Global Search — Real-time Popdown

Search shows a live result popdown as you type — no Enter required. Results span projects, reports, comments, and organisations. Recent searches appear on focus. Clicking a result navigates directly and highlights it on the results page. Contextual filters for status, severity, assignee, and date range also available.

New

Filter & Sort on Every List View

Reports, projects, and organisation lists now feature contextual filters and sort controls. Report filters include status, severity, assignee, and date range. Project filters include visibility and creation date.

New

Bookmark & Watch Reports

Bookmark any report for quick access. Watch a report to receive notifications on status, assignee, or severity changes. A dedicated Bookmarks & Watches view manages everything in one place.

Improvement

Notification Centre Redesign

Cleaner layout, improved empty state, and better invite action cards with inline accept/decline buttons. Unread badges now reflect accurate server-side counts.

UX

Toast Notifications + HTMX Loading Bar

Replaced inline message banners with animated toast notifications — slide in from the top-right, auto-dismiss in 4 seconds, with a countdown progress bar. A thin blue loading bar tracks every HTMX request globally across all pages.

Admin New

Site Announcements

Superusers can post site-wide announcement banners (info / warning / critical / success) visible to all logged-in users. Banners are dismissable and support optional auto-expiry.

New

Account Deletion (Soft-delete)

Users can now permanently delete their account from Edit Profile, with password confirmation. Account is soft-deleted immediately and hard-deleted after a 30-day grace window — log back in anytime before then to reactivate.

New

FAQ, Privacy Policy, Terms & Contact Pages

All essential public-facing pages are now live: a searchable FAQ, detailed Privacy Policy, Terms of Service, and a Contact form that routes messages to the team.

Phase 2.0 Public Beta · July 4, 2026
Feature

Organisation Support

Create organisations, invite members, and scope projects to your org. Assign a dedicated Project Head with full administrative control over org-owned projects, while the organisation owner stays the top-level authority.

Security

3-Level Access Scoping & UUIDv7

Granular permissions enforced across the board: Public, Org-Only, and Private visibility levels. All database records migrated from sequential integer IDs to time-ordered, non-enumerable UUIDv7 identifiers — eliminating IDOR risk entirely.

Audit

Report History & Audit Logs

Full event logging for all project and report modifications — status changes, reassignments, severity updates, and collaborator actions. View a complete change timeline on every report detail page.

UX

Navigation & UX Improvements

Activated Collaborating Projects and Needs Attention views. Integrated the What's New changelog. Unified search box with refresh in a clean widget. Strong password validation with inline feedback on the auth card.

Foundation

Core Project & Issue Tracking
